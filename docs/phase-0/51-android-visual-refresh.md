# Android visual refresh

The refreshed interface takes direction from the supplied REFRACT references:
warm paper and dark ink surfaces, cobalt accents, compact branded headers,
editorial headings and a five-destination navigation bar. It uses actual library
and local analysis data, not the illustrative content in the reference images.
The library is a navigation destination rather than a fabricated reader state;
the evidence vault remains accessible from Home and Settings.

The monochrome monogram, wordmark and launcher artwork are cropped from the supplied
brand reference. The launcher is a raster Android drawable, not an adaptive or
vector icon; the source image's limited resolution can be visible at large
sizes. Production brand artwork and adaptive/monochrome launcher variants remain
future work. Light, dark and system appearance are user-selectable and saved
locally. Existing capture review, consent and partial-export disclosures remain
in place. The visual changes do not implement the product features shown in the
mockups that are not already available.

Flutter and device verification are still required, including small screens,
large text, contrast, navigation, screenshots and the real Android launcher.
